# 📚 Customer Tracking App

This project is a simple customer management system that allows you to add, list, search, and delete customer information. It is written in C and stores customer data in a file.

## 🚀 Features

- ➕ Add New Customer
- 📋 List All Customers
- 🔍 Search Customer by First Name
- ❌ Delete Customer
- 💾 Store Customer Information in a File

## 📦 Requirements

- C Compiler (e.g., GCC)
- Windows Operating System (uses `system("cls")` for clearing the console)

## 🔍 Usage

1. Clone or download the project.
2. Compile the `main.c` file using a C compiler.
3. Run the program.
4. Select the desired operation from the menu.

## 💻 Example Usage

When the program runs, you will see a menu like this:

=== Customer Management System ===

1- Add New Customer

2- List All Customers

3- Search Customer by First Name

4- Delete Customer

0- Exit

Enter your choice:


Follow the options to manage customer information.

## 📁 File Structure

- `main.c`: The main code of the application.
- `customerInfo.txt`: The file used to store customer information.
- `temp.txt`: The temporary file used during the customer deletion process.
